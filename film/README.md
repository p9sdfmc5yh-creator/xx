# 《药食同源》 — photoreal rebuild (two versions)

Both films are 1920x1080, 30 fps, 1248 frames (41.6 s) and carry the original music track
(stream-copied, bit-identical). The cut grid of the original film is kept frame for frame.

| file | what |
|---|---|
| `out/yaoshi_A_1080p.mp4` | Version A: the original "planet horizon" structure; all 29 ingredient / herb shots re-rendered photoreal in Blender Cycles; white paper first and last pages; producer 肖汶玥 |
| `out/yaoshi_B_1080p.mp4` | Version B: top-down specimen plates; 16 ingredients spell 药 / 食 / 同 / 源 in rapid succession and the film lands on 药食同源 poured from goji berries |

## Layout

- `shots.json` (from `shots_src.py`) — version A shot table: frame ranges, labels, art direction per ingredient.
- `shots_b.json` (from `shots_b_src.py`) — version B scene table.
- `timeline.json`, `compose/text.py` — every text element of the original film (string, font, size, position,
  timing), reverse-engineered from the delivered mp4; the producer name is 肖汶玥.
- `blender/common.py`, `blender/README.md` — shared Cycles helpers (framing, heap packing, instancing, materials).
- `blender/shots/<id>.py` — one script per ingredient; each also exposes `make_items()` (loose items for version B).
  `blender/shots/pile_from_items.py` builds a mound from any shot's items (jujube, yam slices, monk fruit).
- `blender/flatlay.py`, `blender/glyph_layout.py`, `blender/b_render_all.sh`, `blender/README_B.md` — version B stills.
- `compose/backdrops.py` — procedural backgrounds fitted to the original; `compose/retro.py` — paper pages + vintage finishing.
- `build_a_1080.py` — assembles version A; `compose/compose_b.py` + `build_b.py` — assemble version B.
- `compose/stereo.py` — depth-based stereoscopic synthesis library (validated on one shot, not used in the delivered cuts).

## Rebuild

```
PY=<venv with bpy 5.3, numpy, scipy, opencv, Pillow>/bin/python
$PY blender/shots/m02_gouqi.py --quality final --res 1920x1080 --out renders_hd/m02_gouqi.png   # one still
blender/b_render_all.sh                                                                         # all version B stills
$PY build_a_1080.py build out/yaoshi_A_1080p.mp4
$PY build_b.py
```
Rendered stills (`renders*/`) are not tracked in git: they are tens of MB each and are regenerated by the scripts.
Fonts: Noto Serif / Sans CJK SC (OFL) from the notofonts/noto-cjk repository.

## Known limits

- Masters are 1080p. Two stills exist in 4K (goji, cabinet); a full 4K pass needs roughly 10-15 CPU-minutes per still on 4 cores.
- Version A, tangerine peel: still built from a 720p preview render (its native re-render broke the framing).
- The text 「在几千年生产生活实践中形成的医学科学」 is kept from the original film; its source wording could not be
  re-checked against the government site from the build environment.
