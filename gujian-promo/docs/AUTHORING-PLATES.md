# 图版作者指南（《中国古钱币》第二版 · 影片 id `coins2`）

## 这支片子是什么

20 秒、25 fps，逻辑画面 1080×1080，**成片按 2160×2160（4K 级）渲染**。结构照着第二支参考片做：先是十来张慢慢移动的老图版（越切越快），然后**几十样东西在每一格里拼成同一个符号**（每格只停 3 帧），最后一格飞散开，落到片名卡。
参考片的符号是数字 5；**我们的符号是字号「志和诚」**：先用 15 格拼「志」、15 格拼「和」、15 格拼「诚」（一个大字占满画面），再用几个停留镜头拼出完整的「志和诚」三个字。

所有画面都是 Canvas 2D 程序绘制。每个图版是一个独立的 ES module：`src/films/coins2/scenes/<文件名>.js`。

```js
import * as L from '../../../lib/core.js';     // 通用绘图库（随机、噪声、颜色、纹理、笔触、pixelCanvas）
import * as K from '../../../lib/plate.js';    // 图版工具（字形符号、排布、纸、物件、镜头）——很短，请直接读
const { S } = K;                               // 1080（逻辑像素）
let layer = null;
export default {
  name: '图版中文名',
  init(env) { layer = build(); },              // 只调用一次：把画面预渲染成图层（可以 async）
  draw(ctx, env, p) { ctx.drawImage(layer, 0, 0); },   // 每帧调用，p ∈ [0,1]；env.frame 是镜头内帧号，env.frames 是总帧数
};
```
范例：`src/films/coins2/scenes/g30-red-dots.js`（朱点拼字，60 行）。

## 符号（最重要的规则）

**你的图版不知道自己要拼哪个字。** 同一个图版会被剪辑表用在不同的格子里，拼「志」「和」「诚」（大字）或「志和诚」（三个小字一排）。播放器在调用你的 `init` / `draw` 之前已经选好了当前符号，你只管用下面的工具，**不要写死任何字形、坐标、笔画数**：

- `K.glyphInfo()` → `{ key, strokeWidth（笔画的典型宽度：大字约 75 px，三字一排时约 28 px）, bbox, chars }`。**物件的大小要跟着 `strokeWidth` 定**，不要写死像素。
- `K.pack({ seed, rmax, rmin, gap, margin })` → 沿笔画塞满圆片 `[{ x, y, r, ang }]`，大的在前：最大的圆片正好落在笔画中线上、和笔画一样宽（像一串珠子），小的补空。`ang` 是该处笔画的走向（长条形的东西顺着它摆）。这是「用物件拼字」的标准做法。
- `K.outline({ grow, spacing })` → 沿轮廓等距取点 `[{ x, y, ang（朝笔画外）, tan }]`（`grow < 0` 往笔画里收）。让东西贴着笔画边缘排、或者沿轮廓走线时用。`K.glyphLoops({ grow })` 给出轮廓折线本身。
- `K.glyphPath(ctx, { grow })` / `K.fillGlyph(ctx, style, { grow })` / `K.clipGlyph(ctx, { grow })` / `K.strokeGlyph(ctx, { grow })`：字形的路径（`grow` > 0 加粗、< 0 收细）。整片材质只出现在字里，或者铺满整页只留出字的空（负形），都靠它。
- `K.sdGlyph(x, y)`：到轮廓的有向距离（笔画内为负）；`K.inGlyph(x, y, margin)`；`K.strokeAngle(x, y)`；`K.glyphNormal(x, y)`；`K.glyphMask({ grow, feather })`。

三种拼法：(1) **物件拼**——`K.pack` 的每个圆片里放一个物件（物件略大于圆片、可以互相压一点，才不露底；先画小的后画大的）；(2) **材质裁切**——一整片材质只留在字形里；(3) **负形**——材质铺满整页，字是留出来的空。

验收：把预览缩成邮票大小，**一眼读得出这个字**（笔画之间的空隙、「和」里的「口」、「志」下面的「心」都没有被堵死）；sheet 第 4 格的洋红线是标准字形，你的字和它重合（物件类是物件的外包络贴线，允许物件探出 6 px 以内）。至少用两个不同的符号预览过（见「流程」）。

## 4K：每一处都要有细节

成片是 2160×2160。画布已经做了处理：**你照常用逻辑像素（1080）写代码，画布背后是 2 倍的设备像素**——凡是用路径、渐变、描边、文字、`K.sprite` / `K.stamp` 画的东西，自动就是 4K 原生精度。只有一种情况例外：

- **逐像素计算**（自己填 ImageData）必须用 `L.pixelCanvas(w, h, (data, pw, ph, q) => { … })`：它给你 `pw × ph = (w·q) × (h·q)` 个**设备像素**，设备像素 (i, j) 对应的逻辑坐标是 `((i + 0.5) / q, (j + 0.5) / q)`，所有量都从逻辑坐标算。不要再用 `createImageData` + `putImageData`（那样只有 1080 的精度，放大后发糊）。
- 物件精灵用 `K.sprite(w, h, draw)` 画一次、`K.stamp` 多处盖，每种物件做 3—6 个不同的变体。
- 细节要画到 4K 也经得起看：一个 70 px 的物件在成片里是 140 px，上面要有可看的结构（边棱、纹路、划痕、高光的亮核），线条 1—2.5 px。

## 立体感（客户点名要「3D」）

俯拍实物类的图版，每个物件都要有**真实的体积**：有厚度（看得见侧壁或倒角）、受光面和背光面、高光有亮核和柔边、落在底面上的接触阴影加一层更软的投射阴影（`K.stamp` 自带一层，可再加）、物件互相压着的地方有遮挡阴影。**光一律从左上来**，投影落向右下。印刷品类的图版（木刻、蓝图、地图、拓片）则要有纸的厚度感：油墨吃进纸里、纸面有纤维起伏和压痕。不要扁平矢量风，也不要塑料感。

## 其他规则

- **文字禁令**：除了被拼出来的那个字本身，画面里不出现任何可读的文字、数字、字母。钱面只画外郭、内郭和磨平的地章，不写钱文；印章的印文是不可读的篆书式线条。
- **客户反感的东西不要画**：贝壳、成排的齿、裂口、密集的孔洞，任何像嘴、像皮肤病的形状。
- 相邻两格的底色反差（白纸 / 黑底 / 蓝晒 / 黄纸……）是这支片子的节奏来源，底色按任务单。
- 每个物件的大小、角度、颜色、磨损都略有不同（`L.rng(seed)`）；禁止 `Math.random()` 和 `Date`。
- 性能（按 4K 预览计）：`init` ≤ 8 秒，`draw` ≤ 80 ms/帧。重的东西都放 `init`。
- 只改任务点名的文件。可以读第一版的场景（`src/films/coins/scenes/*.js`）学画法、抄局部函数，但不要 import 它们。
- 闪切格（3 帧）画面完全静止；慢图版 / 停留镜头用比画面大的图层加 `K.drift` 缓慢移动，或按 `env.frame` 做小而确定的动画。

## 流程（必须照做）

```bash
cd /home/user/xx/gujian-promo
GJ_SS=2 node tools/preview2.js <格子号> --film coins2                 # 按 4K 渲染；Bash 超时设 600000；前台跑；一次一个
GJ_SS=2 node tools/preview2.js <格子号> --film coins2 --glyph 诚      # 换一个符号再看：志 | 和 | 诚 | 志和诚
```
每一轮用 Read 看：`build/coins2/preview/<格子号>_sheet.jpg`（首 / 中 / 末 / 洋红色的标准字形）、`_zoom.jpg`（三处 **4K 原始像素 1:1** 局部——细节够不够就看它）、`_compare.jpg`（左：参考片的对应图版，借的是它的手艺水准和画面密度；右：你的）。自问：

- 缩成邮票大小，一眼读得出字吗？
- 遮住内容只看质感：像老图版 / 实物照片，还是像矢量图？有立体感吗？
- 4K 1:1 下干净、有结构吗？有没有发糊的放大位图、锯齿、色带？
- 有没有不该有的字？预览退出码是 0、没有 ERRORS 吗？
