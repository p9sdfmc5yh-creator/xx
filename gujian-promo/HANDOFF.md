### 客户这一轮提的四件事，分别怎么落实的

1. **「这什么东西，这么恶心，删掉，换成别的」**（指第一版 s04 贝币的齿口特写）。
   - 第一版 s04 整个重画成「戥盘碎银」（浅色背景、铜盘沿、几块碎银）；同类的 s29「出土骨贝」换成「出土钱缘」。两个文件名没改（`s04-cowrie.js`、`s29-bone-cowrie.js`），`timeline.js` 的注释里写明了。

   - `docs/AUTHORING-PLATES.md` 里加了一条禁忌：**不画贝壳、成排的齿、裂口、密集的孔洞，任何像嘴、像皮肤病的形状。** 以后加镜头照此执行。
2. **「宣传片是演变成 5 的样子，那我们就演变成志和诚的样子」**。第二版的符号从方孔圆钱改成了字号：15 格拼「志」、15 格拼「和」、15 格拼「诚」（一个大字占满画面，每格换一种材质），然后四个镜头展示完整的「志和诚」——金箔贴字、铜汁入范、金字牌匾、百钱成字并飞散——最后是片名卡「中国古钱币」和品牌卡「志和诚」。
3. **「4K」**。两支片子都按 2 倍分辨率渲染（见下面「4K 是怎么做的」）。
4. **「3D」**。按「画面要有真实的立体感」来做的：物件有厚度和侧壁、按高度场打光、有接触阴影和投射阴影；第二版开场正中那枚钱是按透视真正转动的（看得见钱缘厚度，投影随姿态变）；牌匾的金字是浮雕并有一道移动的侧光。**这不是立体视频（左右眼），也不是用三维软件建模渲染的**——全部仍是 Canvas 2D 程序绘制。如果客户要的是三维软件那种可以绕着物体运镜的镜头，需要换一套做法（WebGL 或三维软件），等于重做。

### 4K 是怎么做的，哪些是原生精度

- `src/lib/hires.js`：页面带 `?ss=2`（命令行用环境变量 `GJ_SS=2`）时，所有画布背后是 2 倍的设备像素，场景代码照常用逻辑像素写。**用路径、渐变、描边、文字画的东西自动就是 4K 原生精度**；公共库自己的纹理（`noiseTex`、`grainTex`、`bumpLight`）也按设备像素计算。
- 场景里**自己逐像素算的东西**要用 `L.pixelCanvas`（`src/lib/core.js`）才是原生 4K；老写法（`createImageData` + `putImageData`）仍按逻辑分辨率算、再平滑放大。
- **第二版**：24 个材质图版、`p01`—`p04`、`p11`、`p13`、`h2`、`h3`、`z1` 已全部改成原生；线刻类（`p05`、`p06`、`p09`）本来就是矢量；`p07`、`p08`、`p10`、`p12` 里逐像素的部分还是放大的。
- **第一版**：`s01`、`s02`、`s03`（开场三个长镜头）已改成原生；其余 34 个镜头是「矢量部分原生 + 逐像素质感由 1080 放大」。4K 与 1080p 两种渲染逐镜头比对过，构图和明暗一致。要把这 34 个镜头也逐个改成原生，是下一轮的工作量（每个镜头一个代理、约二十分钟）。

### 本轮的事实核查（联网；只看到搜索摘要，未能打开原页面的都标了出来）

画面上没有新增任何说明文字，下面这些只影响「向客户解释为什么选这些东西」时怎么说：

- 圜钱是战国时期的钱，早期圜钱的孔一般是圆的；秦把圆孔改成方孔铸半两。部分证实（中文维基「中国方孔钱列表」镜像、中国日报《道中华》栏目文章，均为搜索摘要）。
- 「榆钱」因形圆薄如钱而得名：多个来源转引《本草纲目》「形状似钱而小，色白成串，俗呼榆钱」。已证实，但这些来源同出一源，不算相互独立。
- 「铜钱草」是天胡荽属（Hydrocotyle）植物的俗称，因叶圆似钱得名；具体指哪个种，各来源说法不一（野天胡荽 H. vulgaris 最常见）。部分证实。
- 「连钱纹」作为传统纹样的名称见于纹样图录的目录，与球路纹并列；它的定义和形制**未能核实**（上一轮的研究文件也标了「无权威出处」）。
- 麻将「筒子」源于铜钱：**未能核实**，检索没有找到直接论证；对外不要这样说。
- 戥子（称金银的小秤）及其铜盘的形制：**未能核实**，检索只找到一件博物馆藏的戥子盒。s04 是示意性的画面。
- 上一轮派出的那个核查代理因用量上限中断，没有交回结果。

## 一、先读这里

**这是什么。** 一个系列宣传短片：每支 20 秒、1920×1080、25 fps，37 个快切镜头共用同一条居中隆起的弧线，后 23 个镜头在弧顶上方叠三拍标语，最后是片名卡并摇回开场画面（首尾相接，可循环）。全部画面由 Canvas 2D 代码绘制，配乐由代码合成。剪辑结构逐帧参照客户提供的一支参考广告。

**现在要继续的是两支**：《中国古玩》（影片 id `antiques`）和《中国古钱币》（`coins`）。另外两支暂停：《中国古建筑》（`arch`）有第一版成片，《中国中医药》（`tcm`）只有初稿。

**当前成片**：`out/zhongguo-guwan.mp4`、`out/zhongguo-guqianbi.mp4`。开场和片尾都已有品牌名「志和诚」。

**客户的要求**（后面的优先于前面的）：

1. 用中文回答；每次回答末尾附一节「来源与核查」。凡是事实都要先联网核实，关键事实至少两个相互独立的来源；没能核实的直接写「未核实」，不许猜、不许编。
2. 代理一律用会话默认的模型，不要换成别的模型。
3. 多对照参考片；画面要细腻。
4. 两支片子的开场和片尾都要有「志和诚」。（已做。）
5. **不要再逐帧精修几个小时。** 客户等不起：先给能让人眼前一亮的成片，再按清单一项项改。只发成片，不要发一堆中间版本。
6. **文案和字体要改**：客户认为现在的文案「太简单，没有什么深度」。见第三节 A、B，等客户选定后改配置即可。

## 二、怎么跑

需要 Node + Playwright（Chromium）、ffmpeg、Python 3（Pillow、numpy）。

```bash
cd gujian-promo
bash tools/fetch-fonts.sh                       # 下载开源字体到 assets/fonts/（不进版本库）
python3 tools/ref-extract.py <参考片.mp4>        # 把参考片拆成每个镜头首/中/末三帧 → build/ref/trio/
                                                # （交接包里已带这些图；只从仓库克隆的话，请客户重新上传参考片再跑这一步）
node tools/preview.js s05 --film coins           # 预览一个镜头 → build/coins/preview/s05_{sheet,mid,compare,zoom}.jpg
node tools/render.js --film coins                # 渲染 500 帧 → build/coins/frames/（约 4 分钟）
bash tools/encode.sh coins                       # 编码 → out/zhongguo-guqianbi.mp4（自动把响度调到 −16 LUFS）
python3 tools/qc.py --film coins --mp4 out/zhongguo-guqianbi.mp4    # 成片质检
```

预览出的四张图：`sheet`（开头 / 中间 / 结尾 / 弧线与文字安全区参考线）、`mid`（中间帧）、`compare`（左参考片、右我们）、`zoom`（三处原始像素 1:1 局部，用来看细腻程度）。画面规范在 `docs/AUTHORING.md`。

**踩过的坑（请照做）：**

- 机器内存有限。渲染脚本已限制全机同时最多 3 个浏览器（`tools/harness.js`），不要绕开它。
- 不要一次开几十个代理。这一轮因此两次把容器撑到重启、四次触发用量上限，白跑了几个小时。一次 8—10 个以内。
- 一个镜头只让一个代理改；不要给流水线里还在跑的代理发消息（会分叉出第二个实例）。
- 整片渲染期间不要改场景文件（每个镜头在渲染到它时才加载）。
- 每个场景只改它自己的文件；公共库 `src/lib/core.js` 不要随便动。
- 认真打磨一个镜头（多轮看图）约半小时。全片 37 个镜头逐个打磨要好几个小时——动手前先问客户要不要。
- 流程脚本的副本在 `docs/notes/`：`refine.js`（对照参考片打磨 → 三联复核 → 第二轮）、`audit.js`（只看不改的独立质检）、`author-film.js`（从任务单画新镜头）。

### D. 声音

- 配乐是程序合成的（`tools/audio.py --film <影片>`），卡点和剪辑共用同一张帧数表，是对齐的；但**从来没有人耳试听过**，只核对了响度和频谱。请客户听一遍，不满意就重调音色预设，或者换成客户自己有版权的音乐（换音乐要保持 20.00 秒，并让重拍落在三拍标语切入的位置：8.72 秒、10.68 秒、12.48 秒，以及片名卡 15.96 秒）。

### E. 文字与事实核查

- 画面上现有的全部文字：三拍标语、片名、印文、号召语、品牌；钱币线图上的「外郭」「内郭」「肉」「穿」；梅瓶线图上的「口、颈、肩、腹、足」；金开元和黄绫钱拓两个镜头底部露出的「開」字上半截。除此以外不应有任何可读的字——印章上的纹样是不可读的篆书式线条。
- 「開」字只按通行字形画了門字头，没有对照真钱拓片；要更严谨就找一张开元通宝拓片核对笔形。
- 核实资料在 `docs/research/coins-*.json`、`antiques-*.json`：每条事实标了「两个以上独立来源 / 单一来源 / 互相矛盾 / 未核实」。只有第一类可以写进画面或说明文字。这些资料只依据搜索结果摘要，没有通读原页面。
- 画面是示意性的插画，不是对具体文物的精确复原；对外介绍时不要说成是某件馆藏的复原。

### F. 导出

- 改完任何镜头：重渲那个镜头（`node tools/render.js --film coins --shots s18`）→ 重新编码 → 跑质检 → 抽看压缩后的画面。
- 目前只有横版 1920×1080。如果要发竖屏平台，需要另做 1080×1920 的版本（弧线构图要重新排，不是简单裁切）——客户没有提，先问。

### G. 想要更"有深度"的其他办法（可选，先问客户）

- **器物名小字**：在前 14 个较长的镜头（0.4—1.2 秒）角落加一行很小的器物名，例如「金开元通宝」「龙洋」。能增加信息量，但每一条都必须先核实，而且字一多就不像参考片那样干净。
- **旁白**：加一段配音能讲出深度，但需要客户提供配音或授权使用的人声素材，目前工程里没有。
- **加长版**：20 秒只够点到为止；想讲清楚一件器物，需要另做 45—60 秒的版本。

## 五、已核实与未核实

已核实（两个以上独立来源，截至 2026 年 11 月）：

- 钱币部位：穿是钱中间的方孔，又称「好」；肉是穿孔以外的钱体；内郭是钱孔四周的凸边；外郭是钱身外周的凸边。来源：[人民网·艺术收藏](http://art.people.com.cn/n/2013/0322/c226026-20878949.html)（2013-03-22）、[百度百科「方孔钱」](https://baike.baidu.com/item/%E6%96%B9%E5%AD%94%E9%92%B1/2557166)、[新浪「古钱币专业术语图文版」](https://k.sina.cn/article_6325802956_1790c17cc00100jnm7.html)。
- 「通宝」是唐初到清末铜钱的通用名称，始于开元通宝。来源：[汉典](https://www.zdic.net/hans/通宝)、[雅昌艺术网](https://m-news.artron.net/news/20260619/n1332615.html)（2026-06-19）。
- 开元通宝钱面四字按上下右左排列，「開」在方孔上方（「开元通宝」「开通元宝」两种读法都是如此）。来源：[中新网](https://www.chinanews.com/cul/2015/03-06/7108284.shtml)（2015-03-06）、[澎湃新闻](https://www.thepaper.cn/newsDetail_forward_1423383)。
- 「包浆」指器物表面经长期氧化、摩挲形成的光泽层。来源：[汉典](https://www.zdic.net/hant/包漿)、[人民政协网](https://www.rmzxw.com.cn/c/2017-07-05/1637139.shtml)（2017-07-05）。
- 「古玩」即古董、骨董。来源：[中新网](https://www.chinanews.com/zhuanzhu/2000-09-25/204.html)（2000-09-25）、[汉典「骨董」](https://www.zdic.net/hant/骨董)。
- 梅瓶部位「口、颈、肩、腹、足」是通行用语；《宣和博古图》是北宋的青铜器图录：见 `docs/research/antiques-a.json`、`antiques-b.json` 里的来源。
- 「志于道，据于德，依于仁，游于艺」出自《论语·述而》。来源：[中国社会科学网](https://www.cssn.cn/skgz/bwyc/202409/t20240904_5775627.shtml)（2024-09-04）、[儒家网](https://www.rujiazg.com/article/27690)。

2026-11-11 复核补充（联网；除注明者外只看到搜索结果摘要，未能打开原页面——本会话的网络是白名单制，博物馆、汉典、澎湃、中新网等站点打不开）：

- 钱币部位：「好」即孔、「肉」即钱体，见《汉书·食货志下》「肉好皆有周郭」及《通典》卷八自注引韦昭「肉，钱形也。好，孔也」（已读到古籍文本镜像的原文行；镜像不是点校本）。爱好者资料里「肉」另有两种用法（内外郭之间的平面；钱体的厚薄），画面上的标注与三种用法都不冲突。
- 「通宝」沿用「至清末」这句话有例外：民国元年（1912 年）仍铸有「民国通宝」「福建通宝」（来源为英文维基和钱币目录站，未打开原页面）。这句话不上画面；对外介绍时宜说「沿用到清末民初」。
- 开元通宝始铸于唐高祖武德四年（621 年）：《旧唐书·高祖本纪》「废五铢钱，行开元通宝钱」、《旧唐书·食货志上》「武德四年七月……行開元通寶錢」（已读到两个古籍文本镜像的原文行）。这条不上画面。
- 钱文读序：《旧唐书·食货志上》原文是「其詞先上後下，次左後右讀之」，字面与今天通说的「上下右左」相反（国家博物馆藏品页的摘要解释为参照系不同）。画面上只露出方孔上方「開」字的上半截，不受影响；但不要把这句古文直接当字幕引用。
- 霞鹜文楷的许可证：SIL Open Font License 1.1，个人和企业均可免费商用，禁止单独出售字体文件（已打开官方仓库 github.com/lxgw/LxgwWenKai 的 README 和 OFL.txt）。
- 「方圆之间 阅尽兴衰」「物有来处 人有所守」：通用搜索引擎没有查到完全相同或高度雷同的现成广告语；商标库没有查，未核实。
